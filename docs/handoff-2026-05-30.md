## Things to know about the codebase quirks

- **DG campaigns store geo at AD GROUP level**, not campaign level. Query `ad_group_criterion` not `campaign_criterion`. Earlier "DG is global" claim was wrong.
- **VIDEO campaigns have heavy API mutation restrictions** (`MUTATE_NOT_ALLOWED` on many fields). Use Playwright with `chrome_profile/` to drive UI when API blocks. Pattern proven for: pausing ad groups, adding geo, renaming campaigns.
- **Google Ads UI status-dot in row lists is `role="img"`** (display-only). To change status, use checkbox + bulk-edit toolbar.
- **Locations input on campaign settings page has no placeholder or aria-label** — find it via JS `document.querySelectorAll('input[type="text"]')` filtered to visible + below y=400.
